# FocusFlow - Study Timer

A simple Pomodoro-style study timer that helps you study smarter and take better breaks.

## Live Demo
https://bhumikadankhade-ctrl.github.io/study_timer/

## Features
- 25-minute study timer
- Separate Study and Break modes
- Dark/light theme toggle
- Clean, responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- `index.html` - page structure
- `style.css` - styling and themes
- `script.js` - timer logic and theme toggle

## How to Run Locally
1. Download or clone this repository.
2. Open `index.html` in any web browser.

## Future Improvements
- Custom timer duration
